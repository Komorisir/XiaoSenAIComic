# 资产 1：森林全景

```txt
电影感奇幻绘本风格的森林全景，一片宁静、富有层次的古老森林，清晨温暖的阳光从画面左上方穿过树冠，形成柔和的体积光与薄雾。远处是层层叠叠的绿色树木，近处有蕨类植物、苔藓、岩石和自然林间空地。画面中央偏右远处可见一棵格外高大、树冠宽阔的古老橡树，作为故事核心场景。色彩以苔绿色、深森林绿、树皮棕色和柔和晨光金色为主，细腻自然，具有高品质动画电影的绘本质感。竖屏9:16构图，前景、中景、远景层次明确，画面上方保留树冠与天空空间，下方保留森林地面。自然、宁静、带有童话氛围。不要出现动物、人物、房屋、道路、文字或水印。
```

验收重点： 森林要有深度，中央有明确的视觉焦点，不能整张图都是密集树叶。

```txt
电影感奇幻绘本风格，一棵高大、古老、枝干粗壮的橡树，树干表面有自然清晰的深棕色树皮纹理，树冠宽阔，绿叶在清晨金色阳光下呈现细腻的层次。树干从画面下部延伸至上部，主干略偏右，一根粗壮、结实、略向上延伸的横向树枝从树干向画面左侧伸出，枝条轮廓清楚，表面有自然树皮纹理，能够承载一只乌鸦。枝条周围留有足够空间供乌鸦落脚和转头，背景是柔和虚化的绿色森林。阳光始终从画面左上方照入，色彩、光线与古老森林场景一致。竖屏9:16，树干和关键枝条完整可见，构图明确。不要出现乌鸦、狐狸、奶酪、人物、文字或水印。
```

验收重点： 这张图决定后续乌鸦的空间位置。枝条必须足够粗、足够清晰，不能被树叶完全遮挡。

# 资产 3：橡树下方空地

```txt
电影感奇幻绘本风格的古老橡树树根与树下空地，粗壮的橡树根从画面右侧延伸至地面，周围覆盖柔软的苔藓、低矮蕨类植物、少量落叶和细小野花。树下中央是一块平坦、自然、开阔的森林地面，空间足够让一只成年狐狸四足站立、行走和抬头仰望。背景为柔和虚化的绿色森林，左上方有温暖的清晨阳光穿过枝叶，地面形成自然柔和的光斑。保持安静、清新、温暖的童话气氛，画面下半部分地面清晰，方便后续角色合成和动作生成。竖屏9:16，高品质电影感奇幻绘本，树根、苔藓和地面细节自然。不要出现动物、人物、奶酪、文字或水印。
```

验收重点： 地面不能被植物铺满。狐狸需要有清晰的站立区域，否则图生视频时容易出现脚部穿模或身体漂浮。

# 资产 4：奶酪道具

```txt
一块独立的浅金黄色硬质奶酪，楔形三角块结构，侧面与切面有少量大小不一的圆形孔洞，边缘自然圆润但保持清晰的几何轮廓。奶酪体积适中，能够被一只乌鸦的喙叼住，也能被一只狐狸叼走。高品质电影感奇幻绘本风格，细腻材质，柔和暖色光线，浅灰色纯净背景，单一道具居中，完整展示正面、侧面和顶面可见的形态。不要盘子、包装、刀具、其他食物、文字或水印。
```

验收重点： 奶酪形状越简单越好。后续每次生成剧情镜头，都尽量使用同一张奶酪参考图，避免奶酪从三角块变成圆形或整块芝士。
