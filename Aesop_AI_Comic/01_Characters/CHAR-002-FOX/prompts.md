# 第一轮：狐狸主形象生成

```txt
一只独立的成年赤狐，自然真实的四足狐狸体态，完整全身展示，四足平稳着地，身体呈自然的四分之三侧面，头部微微转向镜头。狐狸拥有温暖浓郁的橙红色毛发，胸口、下颌、口鼻两侧和尾巴尖端为奶油白色，四肢下半部分为深棕黑色。耳朵高耸且尖，耳背橙红、耳尖深色，眼睛为清澈的琥珀金色，瞳孔细长，眼神聪明机敏、优雅自信，嘴角带有一丝不明显的狡黠感，但整体亲切、讨喜，不凶狠。身体比例自然，腿部修长，毛发细腻蓬松，尾巴粗大且蓬松，具有清晰的体积和柔软的毛发层次，奶油白色尾尖明显。

整体采用电影感奇幻绘本风格，具有高品质动画电影角色设计的精细程度，写实与绘本质感平衡，细腻毛发笔触，柔和的电影级侧光，真实自然的色彩过渡，清晰的角色轮廓。浅灰色无缝背景，柔和地面阴影，主体居中，完整展示耳朵、四只脚和整条尾巴，画面干净，便于后续角色一致性控制。

仅有一只狐狸，不出现其他动物、人物、道具或文字，不穿衣服，不拟人站立，不做夸张卡通大头比例，不要多余肢体、重复尾巴、畸形爪子、模糊面部、过度锐化、塑料质感、文字、水印、边框。
```

建议先生成 4 张候选图，第一轮不要不断修改提示词。先观察生成结果，找出最接近设计目标的方向，再做针对性调整。

# 第二轮：基于选定图片生成角色定稿

选中满意的主形象后，将图片作为参考输入。如果即梦当前模式支持参考图或图生图，请使用该功能。

```txt
严格以输入参考图中的狐狸为唯一角色设计依据。保持原图的头部轮廓、耳朵形状、眼睛颜色、口鼻比例、橙红色毛发、奶油白胸口、深色四肢、蓬松尾巴和白色尾尖完全一致。不得重新设计角色，不得改变年龄感、体型比例和整体绘画风格。

仅优化毛发细节、面部清晰度、四肢结构、尾巴轮廓和整体光影，使角色更清晰、更自然、更适合连续分镜制作。保持四足自然站立、完整全身、四分之三侧面、浅灰色干净背景、柔和电影级侧光。

单只狐狸，无文字、无水印、无多余肢体，不改变原有角色身份。
```

# 第三轮：生成多视角角色参考图

## 正面

```txt
严格以输入的狐狸定稿图作为唯一角色参考。保持同一只狐狸的身份和所有设计特征，包括橙红色毛发、奶油白口鼻与胸口、琥珀金色眼睛、尖耳朵、深色四肢、蓬松大尾巴和奶油白尾尖。

将狐狸调整为正面视角，头部朝向镜头，身体自然四足站立，完整展示全身。保持自然动物结构、原有体型比例、面部特征、毛发质感和电影感奇幻绘本风格。浅灰色干净背景，柔和侧光，主体居中，四只脚和尾巴完整入镜。

只改变观察角度，不重新设计角色，不增加配饰，不改变毛色，不拟人化，不出现其他动物、文字或水印。
```

## 侧面

```txt
严格保持输入参考图中狐狸的角色身份、头部轮廓、耳朵、眼睛颜色、口鼻比例、橙红毛色、奶油白胸口、深色四肢、蓬松尾巴和白色尾尖不变。

将狐狸调整为标准左侧面视角，头部与身体朝向一致，四足自然站立，完整显示鼻尖、身体轮廓、四肢和整条尾巴。保持自然成年狐狸的体态和电影感奇幻绘本质感。浅灰色背景，柔和地面阴影。

只改变视角，不改变角色设计，不增加或减少身体部位，不裁切耳朵、脚爪或尾巴。
```

## 四分之三侧面

```txt
以输入的狐狸定稿图作为唯一角色参考，严格保持角色身份、面部特征、毛色分区、眼睛颜色、耳朵形状、身体比例和蓬松白尖尾巴一致。

生成同一只狐狸的四分之三侧面全身视图。狐狸身体自然站立，头部略微转向镜头，神态聪明、优雅、自信。清晰呈现面部与身体的空间关系，保持自然四足动物结构、电影感奇幻绘本风格、细腻毛发和浅灰色背景。

仅调整观察角度和头部朝向，不重新创作角色，不改变原图的色彩与材质，不添加文字、水印或其他动物。
```

# 第四轮：生成四种核心表情

这一步不需要重新设计角色，只需要验证表情能否服务剧情。

```txt
严格保持参考图中狐狸的角色设计不变，包括脸型、耳朵、眼睛颜色、毛色分区、毛发质感和绘画风格。

只改变面部表情和轻微头部姿态，表现出【得意】的情绪：眼神聪明机敏，眼睑略微收紧，嘴角轻轻上扬，姿态优雅而自信，不过度夸张。

近景角色表情参考图，面部清晰，浅灰色背景，柔和电影级光照，电影感奇幻绘本风格。不得改变角色身份，不得改变毛色和脸型，不添加道具、文字或水印。
```

实际使用时，每次只保留一个目标表情，不要将四种表情同时写进一条生成指令。
